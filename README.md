# 🚀 Curso de Java — Minha Jornada de Aprendizado

Este repositório foi criado para documentar e armazenar toda a minha evolução prática durante o curso de **Java**, ministrado pelo professor **Gustavo Guanabara** na plataforma **Curso em Vídeo**.

O objetivo aqui é registrar a base do meu aprendizado na linguagem, servindo como consulta rápida dos conceitos fundamentais, estrutura de classes e resolução de problemas práticos.

## 👨‍🏫 Créditos e Reconhecimento
